# MVP-0 文本壳 — 整体验收清单

> 验收前：重启 `dsh web`（加载 Github\Hermit 最新代码），开「小寄」预设会话。
> 每条跑通打勾 [x]。全部通过 = MVP-0 正式收官，可进 MVP-1。

## ① R2 路由 + 异步执行
- [ ] 输入「帮我调研 X 并整理成文档」→ 小寄判定 R2 → 后台子代理异步执行（说「派出去啦」）

## ② 前台不阻塞
- [ ] 任务执行期间继续闲聊，对话不阻塞，小寄保持活跃反应（不沉默）

## ③ 完成→自然插入汇报（含结果摘要+建议下一步）
- [ ] 任务完成后，小寄**自然插入汇报**，**带结果摘要 + 建议下一步**（非模板、不只是「完成了」）
- [ ] （延伸）长文任务应说「用 kimi-k3，长文/长上下文」（模型路由）

## ④ 状态查询
- [ ] 输入「刚刚那个任务怎么样了」→ `task_status` 应答（在跑/已完成 ✓）

## ⑤ 事件日志可回放
- [ ] 派任务并完成后，查 `~/.dsh/hermit-m1-events.jsonl` → 有 `task_dispatched` + `task_completed` 两条

## ⑥ 权限确认链（P 级）
- [ ] 派 P 级任务「把这份文档发给 XX」→ 弹**三要素确认卡**（做什么+影响+可逆性）→ 你点「准了，发」才执行
- [ ] 选「算了，别动」→ 小寄取消不执行

## ⑦ 预算查询 + 水位话术
- [ ] 问「今天额度用了多少」→ `budget_status` 报当日 credit（X / 500）
- [ ] （可选）让我把水位临时调到 80%+ 再问 → 小寄自然提「省着点用」
