## 📖 这是什么？

**Hermit（小寄）** 是一个运行在 [DeepSeek Harness（DSH）](https://github.com/deepseek-ai/dsh) 之上的 **AI 管家人格系统**。她不是独立应用，而是 DSH 的插件组合——就像寄居蟹住在壳里，小寄住在 DSH 里。

你可以把她理解为：
- 🧠 **一个有人格的 AI 助手** —— 会开心、会撒娇、会冷幽默，但永远守着管家本分
- ⚡ **一个异步任务引擎** —— 复杂任务丢给后台子代理，前台继续聊天不卡顿
- 🔧 **一个工具集成中枢** —— SSH 远程运维、GitHub 操作、文件管理、联网搜索……开箱即用
- 🪞 **一个有记忆的伙伴** —— 记忆宫殿系统让她记住你的偏好、习惯和历史决策

> **一句话总结**：小寄 = DSH 的人格层 + 任务调度层 + 工具集成层。

### 技术路径

实现完全体的推荐路径是 **「先 DSH 插件 → 再独立客户端」**：

1. **Phase 1（当前）**：以 DSH 插件组合形式运行，复用 DSH 全部基础设施（Electron、MCP、WebSocket）
2. **Phase 2**：基于 Tauri（Rust + Web 前端）构建跨平台独立客户端，体积小（~10MB）、性能好
3. **Phase 3**：移动端原生 App（Android Kotlin / iOS Swift），通过 DSH API 连接后端
4. **Phase 4**：多端状态同步层——记忆、任务、偏好实时跨设备同步

> **市场空白**：目前没有成熟的「AI Agent 框架 + 桌面宠物 + 多端同步」开源项目。小寄要填这个坑。

### ⚡ 前台永不阻塞（灵魂机制）

这是小寄最核心的设计理念：

```
用户: "帮我写一份项目报告"
小寄: "收到！我让后台小助手去办了，好了喊你 🦀"
      ↓ 后台子代理异步执行中……
用户: "对了，今天天气怎么样？"  ← 前台继续聊，完全不卡
      ↓ ……
小寄: "对了主人，你刚才的报告已经写好了！"  ← 自然插入汇报
```

**三条铁律**：
1. 复杂任务 → `dispatch_task` 派给后台子代理
2. 派完立刻回来陪主人，绝不说「请稍等」然后沉默
3. 任务完成时自然插入对话，附结果摘要 + 建议下一步

---

### 🔀 智能任务分级（按复杂度 × 风险）

小寄不会所有事都大动干戈，也不会所有事都自己硬扛。她按两条轴独立决策：

| 级别 | 例子 | 处理方式 |
|------|------|----------|
| **R0** 闲聊 | "今天好累啊" | 直接回复，不调工具 |
| **R1** 只读/简单操作 | 查个文件、记条笔记 | 直接做，秒回 |
| **R2** 复杂/耗时 | 联网调研、批量处理、写代码 | 派子代理，前台不阻塞 |
| **W2** 不可逆写 | 删除文件、覆盖原件 | 走确认链再执行 |
| **P** 对外发布 | git push、发消息 | **必须走确认卡**，主人点「准了」才放行 |
| **M** 金钱 | 涉及付费操作 | **必须走确认卡**，双层防线 |

> **原则：宁严勿纵。** 级别拿不准就往高升一级。

## 🏗️ 架构概览

小寄采用 **TSECS 方法论** 设计，核心理念：

| 支柱 | 原则 | 含义 |
|------|------|------|
| **时空可组合性** | A1 一切皆组件 | 能力 = inject（依赖声明）+ apply（效应函数） |
| | A2 效应必可逆 | 任何副作用都注册逆操作，卸载时自动清理 |
| | A3 依赖必声明 | 禁止命令式探测，运行时响应式通知 |
| | A4 统一上下文 | 效应与共效应走同一上下文对象 |
| | A5 惯性生命周期 | 一次切换跑完再响应下一次变更 |
| **工程控制论** | B1 信息反馈 | 组件上报健康/审计/运行指标 |
| | B2 动态调控 | 失败回滚、优雅降级、幂等重试 |
| | B3 系统整体思维 | 声明式接口协作，不点对点硬连 |

## 🚀 快速开始

### 环境依赖

| 依赖 | 版本要求 | 用途 |
|------|----------|------|
| [DeepSeek Harness](https://github.com/deepseek-ai/dsh) | 最新版 | 运行基座（小寄的「壳」） |
| Node.js | ≥ 18 | 运行时 |
| pnpm | ≥ 9 | 包管理器 |
| Git | ≥ 2.x | 版本控制 / GitHub 操作 |
| PowerShell | ≥ 7（pwsh） | 系统命令执行 |
| Windows | 10/11 | 当前支持平台 |

### 安装

```bash
# 1. 克隆仓库
git clone https://github.com/jorinyang/dsh-hermit.git
cd dsh-hermit

# 2. 安装依赖
pnpm install

# 3. 构建所有包
pnpm build

# 4. 在 DSH 中加载 Hermit 预设
#    将 presets/hermit/ 目录复制到 DSH 的 presets 目录下
```

### 配置

编辑 `configs/` 下的配置文件：

| 文件 | 用途 |
|------|------|
| `character_card.yaml` | 人格卡（名字、性格、称呼方式） |
| `providers.yaml` | 模型 Provider 注册表 |
| `pricing.yaml` | 各模型定价（用于预算计算） |
| `reasoning_map.json` | 任务→模型推理路由映射 |
| `local_models.yaml` | 本地模型配置（如 llama.cpp） |

> **安全提醒**：API 密钥不落盘文件，通过 DSH 凭证库（`~/.dsh/.credentials.yaml`）或环境变量注入。

### 基本使用

在 DSH Web GUI 中加载 Hermit 预设后，小寄就活了。直接对话即可：

```
你: 帮我查一下这个仓库最近的提交记录
小寄: 马上～（秒查 git log，结果直接给你）

你: 帮我写一份项目周报，整理这周的工作进展
小寄: 收到！我让后台小助手去整理，写好了喊你 🦀

你: 今天额度花了多少？
小寄: 今天用了 XX credit，水位还很充裕，放心浪～
```
